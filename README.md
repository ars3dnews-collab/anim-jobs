# Animation Jobs Bot

Телеграм-бот вакансий для 3D-аниматоров: канал [@AnimatorPosition](https://t.me/AnimatorPosition).

Источник — публичная таблица [Animation/VFX/Game Industry Job Postings][sheet],
которую вручную ведёт Крис Мейн. Бот читает её CSV-выгрузку, отбирает
вакансии по анимации, переводит на русский и публикует.

[sheet]: https://docs.google.com/spreadsheets/d/1eR2oAXOuflr8CZeGoz3JTrsgNj3KuefbdXJOmNtjEVM/htmlview

## Главное правило этого репозитория

**Запуск должен быть коротким.** Прочитал таблицу, опубликовал новое, вышел.

Предыдущая версия бота держала запуск живым почти шесть часов, отсыпаясь
внутри между постами, — так удобнее держать ровный ритм. За сутки
набегало 24 часа машинного времени, и GitHub отключил тот репозиторий
за нарушение правил: Actions нельзя использовать как бесплатный сервер.

Здесь ритм держится частыми короткими запусками. Расход — минуты в сутки
вместо часов. Не добавляйте в код ожидание длиннее `POST_GAP_SECONDS`
и не поднимайте `timeout-minutes` в воркфлоу.

## Как это работает

* Каждая вакансия выходит один раз. Ключ считается по студии, должности
  и ссылке.
* Память двойная: `posted.json` в репозитории **и** сама история канала.
  Если файл памяти пропадёт, бот всё равно не повторится — он сверяет
  ссылки с тем, что уже опубликовано в канале.
* Строки с одной ссылкой схлопываются в один пост: студии подают набор
  сразу на несколько городов, и города перечисляются в одной строке.
* Память пишется сразу после каждого поста, а не в конце запуска.

## Настройки

Всё в `config.py`:

| Что | Параметр |
|---|---|
| Какие должности ловить | `WANT`, `SKIP` |
| Не публиковать старее | `MAX_AGE_DAYS`, `MIN_DATE` |
| Пауза между постами в пачке | `POST_GAP_SECONDS` |
| Потолок постов за запуск | `MAX_POSTS_PER_RUN` |

## Секреты репозитория

`BOT_TOKEN`, `CHANNEL_ID`, `GEMINI_API_KEY`.

## Ручной запуск

Actions → Animation Jobs Bot → Run workflow:

* **dry run** — показать в логе, что нашлось, ничего не публикуя;
* **force** — публиковать пачку без пауз.
